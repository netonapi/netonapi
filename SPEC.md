# neton-application-module-template SPEC

> Status: minimal baseline
> Purpose: keep only the smallest module skeleton

## 1. Template scope

This template only provides:

- one module initializer
- one hello world controller
- one tiny test

Everything else must be added per-module based on:

- `/Users/zoujiaqing/projects/Neton/neton-application/docs/module-template-spec.md`

## 2. Template use

This project can be used as:

- an internal module copied under `neton-application`
- an external standalone module repository

## 3. Rename checklist

When creating a real module from this template, rename:

- project name
- package name
- module id
- route prefix
- controller name
- initializer name
