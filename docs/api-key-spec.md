# API Key 规范（2026-10-28）

网关 `/v1`（以及 `/v1beta`、`/v1/messages` 等协议入口）是独立的 `gateway` 路由组，只认 sk- 开头的 API Key（TokenGuard）。
管理台的管理员令牌、控制台的账号令牌都调不了网关接口。这与 platform 开放 API（`open` 路由组，appId + 签名）是同一模式：
**凭据自己的配置决定它能调什么、按什么价格计费、怎么限速**。

## 1. 谁能建 Key

- **只有用户本人**在控制台「API Key」页创建（`POST /app/gateway/token/create`）。调用扣的是他自己的余额。
- **管理台不能代建 Key**（V024 撤掉了接口与 `gateway:token:create` 权限）：后台代建等于运营替用户造凭据，明文还会经过运营的手。

## 2. 明文只显示一次

- 后端只存哈希（`key_hash = SHA-256(sk-…)`）与掩码（前 7 + 后 4），**不留存明文，也不做加密留存后的再次查看 / 列表复制**。
- 创建成功后弹出**模态对话框**展示明文：
  - 醒目警告「请立即复制并妥善保存。出于安全考虑，系统不保存明文，关闭此窗口后将无法再次查看；遗失只能删除后重新创建」；
  - 大号的明文框 + 「复制」按钮（复制后变为「已复制」；剪贴板不可用时提示手动选中）；
  - 点遮罩、按 Esc 都关不掉，只能点「我已保存」；**还没复制就点「我已保存」时二次确认**「关闭后将无法再次查看」。
- 列表只显示掩码。

## 3. Key 上的配置

| 配置 | 谁设 | 说明 |
|---|---|---|
| 名称、有效期、可用模型、预算、IP 白名单 | 用户 | 控制台建 / 改 Key 时设 |
| 计费分组 | 用户在开放范围内选；运营可指定并锁定 | 决定走哪些渠道、按什么倍率计价，见 [key-billing-group-design.md](key-billing-group-design.md) |
| RPM / TPM / 并发上限 | **只有运营** | 管理台「API 令牌」→「限速」（`PUT /admin/gateway/token/update-limits`，`gateway:token:update`）；用户不能自行放宽，自助接口带这些字段一律 400 |
| 启用 / 停用 | 用户与运营 | 停用后立即 401 |

## 4. 管理台「API 令牌」= 监管，不是建 Key

按用户 ID 查看他的 Key（掩码、已用 / 预算、限速、分组及来源「运营指定 / 用户自选」、状态），可以：
停用 / 启用、删除、**指定分组**（锁定，用户改不了；选「default（未指定）」取消）、**设置限速**。

## 5. 验收（harness）

S29（自助建 Key 提不了组、选不到未开放的分组）、S68（自助更新不改限速与运营指定的分组、限速只能运营设、
app 组没有 update-limits 路由）。
